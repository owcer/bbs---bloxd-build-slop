# bbs - bloxd build slop

## `What`
So now you can generate bloxd builds with ai

## `How`
1. Load an AI chat - probably use gemini 3.5 flash (or up) (google ai studio), but other ones would probably work fine as well
2. Copy this prompt: [prompt.txt](/prompt.txt)
3. Paste it to the AI, and wait for it to respond, then tell it what you want to build (or you can also edit the bottom line)
4. Wait for it to generate the code
5. Copy the code
6. Go to a flat test world and open world code
7. Paste the code you copied from step 5
8. Wait for the build to finish
